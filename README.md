# 🌡️ ThermaNexus – AI-Powered Cold Chain Monitoring & Intelligent Rerouting System

## 📌 Overview
ThermaNexus is an AI-powered platform designed to monitor temperature-sensitive medical shipments such as vaccines, blood, organs, and medicines. It provides real-time shipment tracking, predicts spoilage risks using AI, and recommends intelligent rerouting to the nearest cold storage facility, ensuring safe and efficient healthcare logistics.

---

## ✨ Features
- 📍 Real-time shipment tracking
- 🌡️ Live temperature and humidity monitoring
- 🤖 AI-powered spoilage risk prediction
- 🛣️ Intelligent rerouting recommendations
- 📊 Interactive analytics dashboard
- 🔐 Secure user authentication
- 📱 Responsive and user-friendly interface

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Supabase
- **Database:** PostgreSQL (Supabase)
- **AI:** Google Gemini API
- **Hosting:** Bolt

---

## 🚀 How It Works
1. Shipment data is collected and stored in the database.
2. The system monitors environmental conditions in real time.
3. AI analyzes the shipment data to predict spoilage risks.
4. If a risk is detected, the system suggests the best rerouting option.
5. Users can monitor shipment status and AI recommendations through the dashboard.
